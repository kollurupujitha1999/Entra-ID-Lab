# User Management

## Objective
Learn how to create and manage users in Microsoft Entra ID.

## Lab 1 - Create a User

### Prerequisites
- Microsoft Entra ID tenant
- User Administrator or Global Administrator role

### Steps
1. Open Microsoft Entra Admin Center.
2. Go to Identity → Users → All users.
3. Click New user.
4. Enter the required user details.
5. Click Create.
6. Verify the user appears in the user list.

### Expected Result
A new user is created successfully and is visible under All Users.
